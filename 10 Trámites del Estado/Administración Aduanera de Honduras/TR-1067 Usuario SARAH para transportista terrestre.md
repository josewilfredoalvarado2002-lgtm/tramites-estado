## Descripción

El proceso permite la creación de usuario para los transportistas terrestres para el ingreso al Sistema SARAH WEB 2.0 y realizar las operaciones, posteriormente se crea el usuario de SIECA el cual es notificado por la Sección de Transito Aduanero.

## Responsable

Seccion de Control de Registro de los Auxiliares (SCRA) / Sección de Transito Aduanero

## Objetivo

Crear usuario al sistema SARAh para los transportistas terrestres

## Dirigido a

## Requisitos

- REQUISITOS DE CONDUCTOR DE UNIDAD DE TRANSPORTE TERRESTRE
- Estar registrado como transportista terrestre.
- Contar con un contrato de adhesión vigente.
- DOCUMENTOS A ESCANEAR FORMATO PDF Y/O JPG, PREVIO A LLENAR EL FORMULARIO SP048
- DNI del Conductor.
- Licencia de Conducir de carga Pesada Vigente.
